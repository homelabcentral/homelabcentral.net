## What it does

Shortcuts is capable but gapped. Toolbox Pro fills the gaps with actions callable from any shortcut: custom menus and input dialogs, list and text manipulation, file and folder operations, device state queries, calendar and reminder helpers, image work, and utilities for chaining shortcuts together.

It is the difference between a shortcut that automates three steps and one that can present a small interface and branch on what it gets back.

## Notes

- An iPhone and iPad app running on Apple Silicon, which is why the interface is touch-shaped. The actions themselves work in Shortcuts on macOS.
- Free with a one-off in-app purchase unlocking the full action set.
- Actions appear in Shortcuts' action list under the app's name once it has been launched at least once.

## Alternative to

{{< borderless-table >}}
| Alternative | Type | Trade-off |
| --- | --- | --- |
| [Actions](https://github.com/sindresorhus/Actions) | Open source | Sindre Sorhus's free, open-source action pack; the usual first choice |
| [Scriptable](https://scriptable.app/) | Freemium | JavaScript inside Shortcuts, for anything a fixed action cannot do |
| [Pushcut](https://www.pushcut.io/) | Freemium | Automation triggers and notifications rather than extra actions |
| [Keyboard Maestro](https://www.keyboardmaestro.com/) or [Hammerspoon](https://www.hammerspoon.org/) | Paid / Open source | Heavier, Mac-only, far more capable |
{{< /borderless-table >}}
