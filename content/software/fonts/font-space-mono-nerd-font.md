## What it does

Space Mono is a Google Fonts release by Colophon Foundry with deliberately unusual letterforms — angular terminals, a distinctive `g` and `&`, retro-futurist proportions. This is the Nerd Font patched build.

It is a display face that happens to be monospaced. Good for headings, terminal recordings and anything that wants character; harder to read for eight hours than JetBrains Mono.

## Ligatures and OpenType features

There are none to configure. Space Mono ships no programming ligatures, no stylistic sets and no character variants, so `calt`, `ssXX` and `zero` have nothing to switch — the patched build adds the Nerd Font icon range and changes nothing else.

Four styles only: regular, italic, bold, bold italic.

## Notes

Licensed under the SIL Open Font License, so it is usable on the web as well as locally.
